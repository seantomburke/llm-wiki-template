Before doing anything in this repository, read the `AGENTS.md` files for context:

```bash
find . -name AGENTS.md -not -path '*/node_modules/*'
```

Start with the root `./AGENTS.md`, then read any `AGENTS.md` in the
subdirectories you are about to work in — the nearest one to a file takes
precedence over the ones above it.
