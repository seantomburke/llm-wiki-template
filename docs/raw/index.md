# Raw Source Index

Source data for the wiki. Two tiers:

- **`current/`** — living snapshots of present-day state. Refreshed in place.
- **`YYYY/MM/DD/`** — point-in-time captures, filed under the date they were taken. **Immutable.**
  Each day folder carries a `README.md` listing that day's captures.

The folder is *when the capture was taken*; the filename retains anything describing *what it covers*.
